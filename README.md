# AcolheApp

Acolhe App é um projeto web para auxiliar pais e mães atípicos.

## Descrição do Projeto

O Acolhe App foi desenvolvido com o objetivo de oferecer suporte e recursos para pais e mães que enfrentam desafios únicos na criação de seus filhos. Através de uma interface amigável e funcionalidades úteis, buscamos facilitar o acesso à informação e promover a troca de experiências entre os usuários.

## Funcionalidades

- **Comunidade de Apoio:** Um espaço para pais e mães compartilharem experiências e dicas.
- **Encontro de Profissionais:** Auxilia a encontrar médicos e outros profissionais da área na sua região.
- **Busca de Estabelecimentos:** Facilidade para encontrar estabelecimentos acolhedores.

## Tecnologias Usadas

- **HTML5 e CSS3
- **DataBase em MySQL
- **PHP
